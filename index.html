A Signal-Flow-Structured State-Space Model of Optical Dynamic Range Compressors

Riccardo Simionato · Univ. Bordeaux, CNRS, Bordeaux INP, LaBRI · DAFx25

Abstract

Optical dynamic range compressors exhibit complex, time-varying ballistics that make them difficult to model with fixed analytical expressions. This work presents a state-space neural network that mirrors the compressor’s signal flow to improve both accuracy and interpretability. We evaluate the proposed model on the Teletronix LA-2A and Tube-Tech CL 1B optical compressors, comparing it with black-box and gray-box baselines. The model combines a multi-state, program-dependent detector, separate ballistics and static-curve pathways, a conditioned signal-path state-space model, and a feedback topology while preserving causal sample-by-sample processing. We also introduce a Multi-Scale Temporal Dynamic loss that emphasizes discrepancies in attack and release trajectories across several temporal resolutions. The proposed model ranks competitively on every metric for both devices while using only 124 trainable parameters and 245 FLOPs per output sample, substantially reducing the computational cost of larger black-box baselines.

Index Terms: dynamic range compression, gray-box modeling, state-space models, LA-2A, CL 1B, differentiable digital signal processing
